10. **Only an issued memo can be superseded**, and both rows record the relationship.
11. **Transfer exposes verifiable bytes.** Use file attachment when the recipient lacks repository access. For a recipient with canonical-repository access, repository + path + commit SHA + content SHA-256 is equivalent. Paste is never transfer.

13. **One register holds authority:** this file on canonical `main`. Mirrors are read-only. Moving the register requires a recorded authority transfer and never re-keys history.

## Instruments

Design-package cuts are **instruments, not speech acts**: durable artifacts the correspondence executes against (instituted at `.26` per HANDOFF-LEGO-PIPE-024-R1, settling 023-R2 §10 items 1–2; shape per 017 §1.2 and ARCHITECTURE §1a, amended by the review round). **The cut key is `{Instrument, Revision, Cut state}`** — uniqueness on the triple; `Cut state` is immutable identity (a second received state gets a new durable value; a row's key never changes), while `Status` is lifecycle (current · superseded · rejected · recorded-not-imported). **Current cut states:** `as-exported`, `as-reviewed`, `as-committed` — register data, like rule 16's thread names: a new received state may coin a new value, and the validator warns rather than rejects, but an unknown value announces itself because a typo in this field mints an identity. A pin resolves through exactly one row to one `Path` and one `tree_sha256` (normative digest: `design-package-import/v1` x-tree-digest-spec; reference `tools/design_pkg.py digest`). A pin naming only package and revision is a validator error (`.24` ruling). From cut R2 the package label is **DT-DESIGN**; lineage crosses the rename via each manifest's qualified digest-bound `supersedes`, and **no alias redirects `H-01` pins to `DT-DESIGN`**.
