# Technical design still required

This package introduces no production schema.

- Separate transient tour position, entry bookmark, active page, room-flight cancellation and modal focus state from durable work history.
- Preserve original proposals, AI origin, human correction, verification and authority as separate facts. A visual ripple or room position is not a durable event schema.
- Design the production dependency model and history before replacing the local mock reading/fit/review flow.
- Specify the build/story record and distinct consent states before persisting family material or using it in a shared model.
- Agree artifact and activity identifiers before live minifigs route to agent work. The current room map and demo markers are illustrative.

The R4 whole-board state and document transitions are known wireframe limitations. A store, rendering structure, sidebars, ledger ownership, routing and scene lifecycle need a dedicated technical session. Passing this package's manifest check settles none of them.
