## Prototype: Can the LEGO House be a useful parallel entry to Drafting Table work?

Mode: ui
Run: `pnpm dev --port 4188` in this directory; house, exploded, and landscape URLs are in README.md.

### Observations

The supplied geometry supports 21 selectable building modules. Pointer and keyboard entry opened the same sheets and returned to the previous camera/focus. The guided box/book/three-bag journey completed with shared mock state; changing a measurement after review reopened the dependent checks and retained earlier readings. The story landscape preserved individual words and proposals. Lite and 2D routes remained usable when the detailed model was absent. Full observations and limits are in VERIFICATION.md.

### Verdict

The original portal was rejected visually and the user reported nausea. The current revision responds with a PLAY WELL poster and the subsequently requested scroll drone route: lobby, broad tree curve, rear exit, assembling house, and return to the front. The route runs in the local preview; camera and assembly reverse together. Still and reduced-motion modes freeze the scene, and sheet entry leaves the camera unchanged. This revised composition awaits the user’s review. A useful handoff requires real sheets, visible state consequences, and exact return behaviour. The model animation export and the physical-box/work-box collision both failed the first implementation and were corrected.

This does not establish that 3D improves wayfinding, that the family method is effective, or that the asset/performance budget works on low-power devices. Test those claims before choosing a production architecture.

Kept (marked) as a local review artifact, following the user's explicit request for a robust runnable prototype. The code lives outside the production checkout. No public deployment or production PR was requested.
