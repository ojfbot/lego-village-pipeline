TURN 1 · HOW EACH KIND OF SHEET SAYS WHAT IT IS · ALL 15 SHEETS + HUB

Every sheet opens the same way, so only the letter in the code tells them apart.

Today every page opens with a serif title, a mono code line, ← HUB and a paragraph, all in the same 1180–1320px column. You only learn which kind of page you're on by reading. Two things have to come first. One is a census: there are ten kinds, and each has its own verb. The other is a constraint: color is already taken. Evidence states own every hue (pass, provisional, blocked, info, unresolved), and the axes have to stay separate. So the kind of sheet can't be carried by color. It has to be carried by form: a mark, a word, a silhouette, a position.

1aThe nameplateRAMS · RAND

Braun puts the model plate in the same place on every device. Rand's point was that a mark identifies, and its meaning comes from use. So: one fixed plate, top-left of every sheet, holding a mark and a plain noun. The same mark shows up on Hub cards, CrossRef chips, links and the tab icon, so you know where a link goes before you click it.

1dThe drawing setSACHS · CONSTRUCTION DOCUMENTS

This is already a Drafting Table, and architecture's document set solved this long ago. Each sheet type has a real-world form: plan, schedule, RFI, submittal, purchase order, receiving report, transmittal. 1eThe thresholdPETER CARL · PRAXIS

Carl: a place is known by the action it hosts and the moment it hosts it in (ethos, kairos). A page is a room you enter partway through the work. So every sheet opens with a three-part threshold: where you came from, what this room is for, and what will have changed when you leave. The kind of sheet shows up as the kind of act and what it commits you to. This is your "frictionless teacher" principle in its purest form.

MY READ · DON'T BLEND, LAYER (YOUR "NEVER BLEND AT THE SOURCE")

Each one solves a different moment. 1c works before reading: the silhouette. 1b works in the first second: the verb. 1e works in the first ten seconds: the consequence. 1a works away from the page: the mark on links, chips and Hub. A layered stack would be: skeleton from 1c, verb as the one shout from 1b, threshold strip under it from 1e, and the mark from 1a everywhere else. 1d becomes the footer, where the sheet number and trade name stay available without leading.
