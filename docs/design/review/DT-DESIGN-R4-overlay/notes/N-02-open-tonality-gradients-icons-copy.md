# N-02 — Still open: gradients, tonalities, icons, copy

Filed 2026-10-10. Real progress on structure, motion and identity; **not** a visual sign-off.

## Unanswered
- **Gradients / washes.** X-01 v2 uses two radial washes (accent, info) at low alpha that gather with depth. Their hue, alpha, position and whether they belong on every sheet are undecided. The operator's instruction stands: transitions should move the layered backgrounds too ("the canvas should breathe").
- **Tonalities.** Hatch escalation (card → draft → tint) is used as a state language in X-01 v2 (open = tint, rail = draft). Whether that mapping is right, and how it meets the evidence hatch rules in `dt/tokens.css`, is open.
- **Semantic variation of chrome.** The operator likes the Drafting Table specimen as-is and does NOT want every bar and card to receive the same border/shadow/hatch. W-00 moved header/footer/sidebars to flat rules and varied card chrome by state (unknown = dashed unres, register = light rule, trusted sheet = hatch + shadow). Rules for this need writing into D-01.
- **Icons.** The ten kind glyphs and the lens marks are placeholders drawn for the census. The project icon set is not chosen.
- **Copy.** Verb set for the ten kinds (See today · Arrange · Answer · Look up · Look closely · Confirm · Approve · Buy · Find your way · Hand over), the threshold strips, Benny's voice and the ledger sentences are first drafts. Nomenclature research (RESEARCH-01) still governs scale words.
- **Which identity layering.** The recommendation (skeleton 1c → verb 1b → threshold 1e → mark 1a → title block 1d at the foot) is the designer's read; the operator has not picked.
- **White blocks.** The operator never wants large white fills, even on buttons. `--dt-plate` answers it on X-01 v2 only; sweep pending.
