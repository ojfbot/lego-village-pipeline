SCHEMA THIS SHEET NEEDS
Set.have_state: owned · approved · planned · idea, Set.build_state: standing · apart · boxed, Set.pieces_available: free · kept — three axes, never fused into one enum. Each carries provenance (who said so, when, how: said · receipt · photo). Build and pieces states exist only while owned; standing implies kept. Only free releases the set's inventory to Earmark. Measurements recorded on a set (M-01) survive taking it apart.
Inventory changes are append-only: a state change is a new row with the old one kept and struck, same as measurements.
